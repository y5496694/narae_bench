# 중첩 인자 설명 수정 확인 · v2.2

전체 벤치 점수와 분리한 3개 과제의 대응 확인입니다. 모델마다 36개를 실행한 [v2.1 전체 비교](../model-comparison-20261019/README.md)를 대체하지 않습니다.

| 모델 | 수정 전 | 수정 후 |
|---|---:|---:|
| 나래1 0.6B SFT v1 | 2/3 | 2/3 |
| 나래2 2.4B SFT v1 | 1/3 | 1/3 |
| Qwen3-4B-Instruct-2507 | 1/3 | 2/3 |

대상은 WXS 작성 `NP-E-WXS-WRITE-01`, 나이스 복무 `NP-N-03`, 변경하지 않은 대조 과제 `NP-P-01`입니다. 실패를 살펴보고 선택한 과제이므로 무작위 표본이나 전체 성능 추정이 아닙니다. v2.1 전체 점수에 이 결과를 합산하지 않았습니다.

`wxs.apply`와 `neis.prepare`의 설명에 `args` 구조를 `{"fields": {}}`로 명시했습니다. 정답값이나 새로운 업무 예시를 추가하지 않았습니다. 각 대응 과제의 최초 메시지에서 이 도구 설명 외의 입력이 그대로인지 확인했습니다. 같은 모델·어댑터·네이티브 실행 파일·서버 명령을 사용했고, 8턴·2,048토큰·temperature 0·seed 719·JSON Schema 조건도 유지했습니다. 실제 모델 출력과 CLI 도구 호출·관찰 일치 및 토큰 사용량을 확인했습니다. 가중치 추가 학습과 실서비스 동작은 0회입니다.

v2.2에는 Windows 읽기 핸들로 원자적 파일 교체가 잠시 막힐 때 1초 한도에서 재시도하는 처리도 추가했습니다. 실제 `FILE_SHARE_DELETE`가 없는 읽기 핸들로 오류를 재현하고, 핸들 해제 후 새 결과 저장과 임시 파일 정리를 검증했습니다. 채점 조건과 정답은 변경하지 않았습니다.

이 확인에서 Qwen 4B의 복무 과제는 실패에서 통과로 바뀌었습니다. 나래1·2의 통과 수는 같았습니다. 다음 가중치 학습에는 도구 호출·응답 관찰·오류 수정·완료 보고를 잇는 여러 단계 자료가 필요하며, 이번 설명 수정을 가중치 학습으로 표현하지 않습니다.

[기계 판독 결과](diagnostic.json), 모델별 대화·도구 증거, 가중치 로드 명세와 실행 소스를 함께 공개합니다. 서버 로그·모델 가중치·실제 계정 정보는 포함하지 않습니다. v2.2 전체 36개 모델 점수는 이 확인에서 측정하지 않았습니다.
