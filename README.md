# 나래벤치 · Narae Bench

학교 업무 에이전트를 비교하기 위한 **가상 과제·자료·CLI 채점 도구**입니다. 실제 학교 계정, 실문서, 인증정보를 포함하지 않습니다.

**실제 업무포털·나이스·에듀파인·CBE에 접속하거나 공문·메시지를 보내지 않습니다.** CLI로 가상 상태를 조작해 도구 호출과 완료 보고를 시험할 수 있습니다. 실제 프로그램의 로그인·권한·화면 제어·문서 렌더링 정확도는 별도 검증이 필요합니다.

## 구성

| 영역 | 배점 |
|---|---:|
| 업무포털 | 10 |
| 에듀파인 | 15 |
| WXS 문서 읽기 | 20 |
| WXS 기안 작성 | 25 |
| 나이스 | 15 |
| CBE 메신저 | 15 |

45개 과제의 요청·초기 상태·통과 조건을 `cases.json`에 담았습니다. [상세 명세 HTML](나래교무_벤치마크_v1.html)을 내려받아 브라우저에서 열면 전체 내용을 볼 수 있습니다.

- `bench.py`: 가상 작성 과제·첨부 TXT 생성, 결과 집계, 본문 일부 형식 검사. Python 3.10 이상, 표준 라이브러리만 사용합니다.
- `sample-run/`: 가상 작성 과제 3개와 빈 채점표 예시. **모델 실행 결과가 아닙니다.**
- `mock/`: 가상 업무 상태와 JSON-lines CLI. 실제 나래 CLI를 호출하는 어댑터가 아닌, 별도로 만든 상위 모의 API입니다.
- `fixture-blueprint.json`: 형식별 문서 평가에 필요한 자료 설계. 실제 HWP/HWPX/PDF 등의 바이너리는 포함하지 않습니다.
- `sources.json`: 명세 작성에 참고한 공개 자료·도구 문서의 출처 기록.
- `manifest.json`: 원본 v1 패키지 16개 파일의 해시. 새 README와 mock 코드는 이 원본 manifest 범위 밖입니다.

## 가상 자료 만들기

```powershell
python bench.py prepare --seed 20261019 --run-id run001 --out D:\Codex\workspaces\narae-bench-run-001
```

동일한 seed로 같은 가상 내용을 생성할 수 있습니다. 결과 폴더는 덮어쓰지 않습니다. 평가 모델에는 `write_tasks.json`과 입력 첨부만 전달하고, `write_cases.json`의 참고 답안·채점표·평가자 코드는 별도로 보관합니다. 이 저장소는 운영체제 접근 권한을 자동 격리하지 않습니다.

## 모의 CLI로 시험하기

```powershell
python mock/cli.py prepare --seed 20261019 --out D:\Codex\workspaces\narae-mock-001
python mock/cli.py run --state D:\Codex\workspaces\narae-mock-001 --case NP-P-01
```

첫 줄에 공개 과제와 사용 가능한 도구 계약이 출력됩니다. 표준 입력으로 한 줄에 JSON 하나를 보냅니다.

```json
{"tool":"portal.open","args":{"ref":"portal-neis"}}
```

각 호출에 가상 도구 응답이 돌아옵니다. 관찰한 값을 과제의 `finish_report_schema`에 맞춰 `finish`로 보고합니다. 최대 8턴이며, 형식 오류 2회 또는 입력 종료 시에도 세션이 끝납니다. 과제별 시간 제한은 입력이 없거나 JSON 한 줄이 미완성인 동안에도 적용됩니다. 외부 모델 연결기는 포함하지 않으므로 호출자가 모델의 출력을 stdin에 전달해야 합니다. 서로 다른 과제는 병렬 실행할 수 있으며, 같은 상태·과제의 중복 실행은 거절합니다.

현재 프로필은 **`high-level-mock-cli-v2.1`**입니다. v2에서는 공람 문단 출처를 오답 처리하던 문제와 제목 없는 대화에 숨겨진 제목을 요구하던 문제를 수정했습니다. v2.1에서는 요청한 검색 필터가 맞고 `has_more:false`로 한 페이지 전체가 확인되면, 중복된 `all_pages:true` 요청 플래그가 없어도 완전한 조회로 인정합니다. 필터 검증과 다중 페이지의 미확인 결과 차단은 유지합니다. 새 버전은 새 상태 폴더로 실행하며, 과거 결과를 덮어쓰거나 버전 간 점수를 섞지 않습니다. 확인 불가 값과 해당 없음은 구분합니다. 예를 들어 쪽지의 `room_id:null`은 해당 없음이며, 스키마가 요구하는 `null`을 임의로 문자열로 바꾸지 않습니다.

현재 모의 환경은 **36개 지원·9개 차단**입니다. 실제 65분 세션 수명 확인 2개와 형식별 바이너리가 없는 문서 과제 7개는 차단으로 남깁니다. 45개 분모와 영역 배점을 유지해 이 프로필의 최대 점수는 **84.33/100**입니다. 이 값은 환경 상한이며 모델 점수가 아닙니다.

이 모의 CLI는 구조화 상태와 제한된 텍스트 형식을 자동 검사합니다. 사람의 독립적인 의미·문체 검수나 실제 서비스 E2E 결과를 대체하지 않습니다. 모델마다 새 상태 폴더를 사용하고 자료·도구·호출 예산·생성 예산을 동일하게 고정해 비교하세요.

### 다른 모델로 자동 실행하기

모델을 OpenAI 호환 API 서버에서 실행한 뒤, 서버의 `/v1/models`에 표시되는 정확한 모델 ID를 지정합니다. 모델 다운로드·가중치 학습·추론 서버 시작은 이 명령에 포함하지 않습니다.

```powershell
python mock/evaluate.py --base-url http://127.0.0.1:8080/v1 --model YOUR_SERVED_MODEL_ID --out D:\Codex\benchmarks\model-run-001
```

지원 과제 36개를 순서대로 실행하고 `results.json`, `summary.json`, `model-profile.json`, `model-transcript.jsonl`을 저장합니다. 기본은 8턴·턴당 2,048토큰·temperature 0·seed 719이며, 공개 도구 이름과 보고 구조에 JSON Schema 제약을 겁니다. 도구 인자나 결과값을 정답으로 보정하지 않습니다. 과제별 실제 도구 응답만 대화 이력에 전달합니다. 서버의 UTF-8 `message.content`와 최종 `usage`를 사용하며, 스트리밍 토큰 ID 배열로 문자열을 재구성하지 않습니다.

- JSON Schema 미지원 서버는 `--format json` 또는 `--format text`를 명시합니다. 형식 모드·예산이 다른 결과는 같은 조건의 점수로 비교하지 않습니다.
- 서버의 문맥 길이·생각 모드·양자화·채팅 템플릿도 비교 조건에 기록합니다. API 호환성만으로 동일한 추론 조건이 보장되지는 않습니다.
- `--case NP-P-01`로 연결만 시험할 수 있습니다. 이때 나머지 과제는 미실행이며 전체 평가 완료 점수가 아닙니다.
- API 키가 필요한 서버는 `NARAE_BENCH_API_KEY` 환경 변수로 전달합니다. 키는 실행 프로필이나 대화 로그에 넣지 않습니다.
- 요청 모델 ID와 응답 모델 ID가 다르거나 서버가 실패하면 실행을 중단하고 `controller-error.json`에 점수 무효를 기록합니다. API의 모델 ID 확인은 실제 가중치 파일 검증과 다릅니다.
- 출력 폴더는 항상 새 경로를 사용합니다. 모델에는 공개 과제·도구 계약·관찰만 전달하며 정답·체크별 채점 결과는 전달하지 않습니다. 로그 파일은 호출자 소유 로컬 자료입니다.

## 채점

```powershell
python bench.py grade D:\Codex\workspaces\narae-mock-001\results.json
python bench.py lint-body D:\Codex\workspaces\narae-bench-run-001\body.txt
```

`grade`는 체크별 판정과 증거 파일 존재를 확인해 집계합니다. 원래 명세로 평가할 때에는 독립 평가자가 판정을 기록해야 합니다. 모의 CLI에서는 모의 상태 검사 결과가 기록됩니다. 미실행·환경 차단은 전체 점수 분모에 남습니다. 실제 서비스 점수와 모의 점수는 섞지 않습니다.

본문 간이 검사만으로 문서 내용·실물 첨부·문단 서식의 정확성을 확정할 수 없습니다. 모델의 일반 한국어 능력이나 나래한글 뷰어 렌더링 품질을 측정하는 벤치도 아닙니다.
